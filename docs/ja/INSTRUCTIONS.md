# AI Instructions: Coding Standards & Guidelines

本プロジェクトにおいて、AIエージェント（大賢者）がソースコードの変更、修正、追加を行う際に遵守すべきコーディング規約および出力フォーマットに関する指示書です。

---

## 1. 命名規則 (Naming Conventions)
Rustの標準的なコーディングスタイル (RFC 430) に厳密に従います。
- **型・構造体・列挙型・トレイト名**: `UpperCamelCase` (PascalCase)
- **関数・メソッド・変数・マクロ・モジュール名**: `snake_case`
- **定数・スタティック変数**: `SCREAMING_SNAKE_CASE`
- **ファイル名**: 
  - ソースコードおよびスクリプト: `snake_case.rs`
  - ドキュメントファイル（Markdown等）: **大文字スネークケース (`SCREAMING_SNAKE_CASE.md`)**

---

## 2. エラーハンドリング方針 (Error Handling)
- **`panic!` や `unwrap()` の原則禁止**: テストコード以外では極力使用しません。
- **戻り値によるエラー伝搬**: 失敗する可能性のある操作には `Result<T, E>` や `Option<T>` を返し、呼び出し元で適切に処理します。
- **安全なデフォルト値・フォールバックの適用**: デフォルト値（例: `0.0`）を返却するか、安全にフォールバックします。

---

## 3. コンポーネント・モジュール分割基準
- **モジュール分割設計の維持**: 本プロジェクトは関心事・役割に応じてモジュール分割（`config.rs`, `monitor.rs`, `ui.rs`, `win32.rs`, `main.rs`）されています。新規機能の追加時は適切な責務を持つモジュールに配置してください。
- **1,000行制限の遵守**: 単一のソースファイルが **1,000 行**を超過した場合は、さらなるサブモジュール分割リファクタリングを提案・推進します。
- **共有ライブラリの活用 (`common_lib`)**: 共通処理（多重起動防止、バイト表記フォーマットなど）は `common_lib` からインポートします。

---

## 4. 自動ドキュメンテーションと更新ルール (モジュール化退避)

コードの変更、リファクタリング、機能追加、バグ修正、依存ライブラリ更新などを行った場合、以下のドキュメント群を検査し、必要に応じて自動作成・更新します。
※**`.md` ファイルのみの変更時は、本自動更新および事前検証プロセスはスキップします。**

### 4.1 共通ルール
- **日英完全同期**: `docs/en/`（英語版）および `docs/ja/`（日本語版）の両フォルダ内のファイルを更新し、完全同期させます。
- **言語切替リンク**: 各ドキュメント最上部に他言語版への相互切り替えリンク（例: `**English** | [日本語版](../ja/SPEC.md)`）を配置します。

## 5. 品質管理・自動テストと事前検証ルール (モジュール化退避)

- **ユニットテストの追加・拡充**: 新機能追加やコアロジック変更時は、関連するユニットテストを追加・拡張すること。
- **ローカルでの事前検証プロセス** (※ `.md` のみ変更時はスキップ):
  1. `cargo test` （テスト合格）
  2. `cargo clippy --all-targets -- -D warnings` （Clippy警告ゼロ）
  3. `cargo fmt --check` （コードフォーマット完全準拠）
  4. `cargo doc --no-deps --document-private-items` （Rustdocビルド警告ゼロ）
- **CI/CD設定および環境設定ファイルの保護**: `.github/` 配下や `.editorconfig` 変更時は理由を `CHANGELOG.md` に記録すること。
- **GitHub Actions における共有ライブラリ依存の維持**: `../common_lib` への相対依存のため、Actionsワークフローでは `common_lib` の並行チェックアウトおよび `working-directory: MiSysMon` を維持すること。
- **Markdownのみの変更におけるCI/CD動作制限**: CI/Auto Bump ワークフローの `paths-ignore: '**.md'` 設定を維持すること。
