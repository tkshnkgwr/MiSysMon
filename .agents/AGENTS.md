# AI Agent Instructions for Mini System Monitor (MiSysMon)

本プロジェクトにおける大賢者の開発指示書です。
最優先ルール（コミット禁止・テーブル整列等）は [GEMINI.md](../GEMINI.md) を参照してください。

## 🎯 開発・品質ルール

- **技術解説方針（他言語経験への配慮）**:
  - ユーザーは他言語の開発経験者ですが、**Rust/React/TypeScript固有の言語仕様・専門用語（所有権、ライフタイム、トレイト、フック等）には不慣れ**です。
  - 難解な専門用語をそのまま多用せず、一般的・共通的なプログラミング概念（参照, インターフェース, モジュール, 関数など）に置き換えるか、直感的に理解できるよう分かりやすく補足・解説を添えること。
- **事前検証とドキュメント同期**:
  - 開発およびドキュメント更新の際は、必ず [`docs/ja/INSTRUCTIONS.md`](../docs/ja/INSTRUCTIONS.md) に記載されている「対象ドキュメント一覧と更新ルール」および「品質管理・事前検証プロセス」に厳格に従って検証・同期を行うこと。
  - **Markdownのみの修正時**: Rustの事前検証（`cargo test` / `cargo clippy` / `cargo fmt` 等）は省略し、迅速に対応すること。
- **コード規模とリファクタリング**:
  - 単一のソースファイル（`src/main.rs` 等）のコード行数が **1,000 行** を超過した場合、関心事・役割に応じたモジュール分割リファクタリングを積極的に提案・推進すること。
